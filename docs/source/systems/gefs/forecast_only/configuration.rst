######################################
GEFS configuration and output products
######################################

===================
Configuration Files
===================

GEFS configuration is primarily managed through the config files in the ``dev/parm/config/gefs/`` directory. Structure is very similar to that of GFS, so see the GFS configuration documentation for more details.

===============
Output Products
===============

* grib2 gridded atmosphere forecast on various grids, including ensemble mean
* forecast model soundings
* NetCDF marine gridded forecast, including ensemble mean
* wave gridded and point forecasts, including ensemble mean
