#####################################
SFS configuration and output products
#####################################

===================
Configuration Files
===================

SFS configuration is primarily managed through the config files in the ``dev/parm/config/sfs/`` directory. Structure is very similar to that of GFS, so see the GFS configuration documentation for more details.

===============
Output Products
===============

* grib2 gridded atmosphere forecast on various grids, including ensemble mean
* NetCDF marine gridded forecast, including ensemble mean
* wave gridded and point forecasts, including ensemble mean
